# ADR-0014：统一前端基础组件

> 分类：Architecture Decision Record
> 状态：Accepted
> 日期：2026-10-21
> 接受依据：用户要求检查并统一项目中的前端组件，沿用 ClipJar 已接受的组件选型。
> 影响范围：SPEC-0015 日常界面，既有表单与辅助入口
> 替代关系：不替代既有领域、存储或产品决策

## 背景

当前基础按钮和输入控件在多个业务组件中重复实现。ClipJar 已采用 shadcn/ui Nova、Lucide、Motion 和 Zustand，用户要求复用其基础选型。统一组件不意味着将各产品都改成相同颜色或页面布局。

## 决策与边界

- React 基础控件采用同一套 shadcn/ui Nova 源码和主题令牌，图标采用 Lucide，交互动效按需使用 Motion。
- 保留冷白、石墨黑与朱橙；不增加导航、AI 行为或数据写入。
- 现有领域数据、表单草稿及业务校验继续由原有 API / 业务进程负责；全局纯界面状态可使用 Zustand，不能把后端事实源迁入浏览器缓存。
- 首批统一实际使用的按钮、输入和文本域；原生选择控件、已有菜单键盘、模态焦点与危险操作确认契约保持有效，迁移必须通过既有回归。
- 不为对齐选型而增加尚无对应功能的分栏和拖拽依赖。

## 后果

统一尺寸、焦点和控件变体，降低后续维护成本；引入组件依赖与 Tailwind 构建管线，需要验证桌面打包与 DOM 测试。框架或组件库不改变产品事实与 Spec 状态。

## 验证

按 SPEC-0015 的按钮、菜单、草稿和恢复场景回归，运行 docs:check、npm test、typecheck、build，并检查实际界面。未完成实机验收的既有 Spec 仍保持 Implemented。
