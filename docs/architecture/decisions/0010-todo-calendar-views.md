# ADR-0010：基础 Todo 与日历共用任务事实

> 状态：Accepted
> 日期：2026-10-04
> 接受依据：用户明确要求先稳定基础 Todo 和日历等视图，再做 AI 增强。
> 影响范围：SPEC-0010、SPEC-0012、SPEC-0013、导出恢复与导航

## 决策

- 保留主线、我的画像两个一级入口；主线内部增加任务列表、今日、月/周日历。
- 视图共用 Action，不复制任务、不为日历建立第二套业务状态。
- `scheduledDate` 是可空的 `YYYY-MM-DD` 本地民用日期，范围 1900—9999；不是 UTC 时间点，也不等同于截止时间。
- 用户可以按 ID 直接完成、撤销完成、移除和恢复任务。状态写入必须带 `expectedStatus`，旧窗口返回冲突并刷新；处理当前任务只释放对应 ID，不干扰其他当前选择。
- 移除复用 abandoned 状态，保留来源关系，可由用户恢复；superseded 不允许恢复以避免拆分重复。
- schemaVersion 7 导出日期；v6 导入显式补空日期。v7 缺失或非法日期拒绝导入。数据库只追加迁移。
- 当前阶段不调用 AI，不增加同步、提醒、团队权限或自动安排。

## 后果

同一任务在不同视图与小窗保持一致。日期不受时区转换偏移；月历固定六行避免翻月时按钮跳动。代价是维护日期校验、旧备份兼容和多窗口状态冲突测试。
