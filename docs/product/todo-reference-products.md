| 产品与来源 | 官方能力 | 本产品的取舍 |

| [Super Productivity](https://github.com/super-productivity/super-productivity) | 任务/子任务、项目分类、Planner、日程时间线与专注工具 | 借鉴捕捉→安排→执行，先把勾选与撤销做轻；暂不引入计时、复杂同步与时间块 |

## 已采用的体验规则

1. 勾选任务就是完成，不必先进入专注；专注仍服务“当前只做一件”。
2. 日期只代表安排哪天做。无日期与逾期可见；避免把安排日、截止日和完成时间混成一回事。
3. 列表、今日、日历切换改变展示，不复制任务。写入提交后刷新进度、画像和其他窗口。
4. 月历固定六行，翻月操作位置稳定。格子预览以外仍可打开当天完整列表。
5. 删除采用明确确认、可恢复移除。误点完成可撤销，多窗口旧操作返回冲突。

官方能力来自上述来源；采用哪些规则属于本项目的设计判断。后续真实用户试用再验证是否降低记录和安排的成本。
