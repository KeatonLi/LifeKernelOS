## 用户结果与范围

用户在设置填写服务地址、模型和自己的 Key，从任务详情请求拆解，编辑并选择建议，确认后形成有来源的小任务。

In scope：一个连接的配置/替换/移除、系统加密或仅本次运行、已保存配置的连接测试、单任务拆解、取消与重试、明确采纳和撤销。

Out of scope：Anthropic 原生协议、云端托管 Key、自动排期、AI 对话首页、自动执行、人生优先级或人格推断、联网搜索、工具调用、全库上传。兼容 Web 入口不保存或使用 Key。

## 配置与安全

1. 展示 Base URL、模型名、密码型 Key 输入与保存方式。提供 DeepSeek 示例和自定义兼容地址；模型可修改。
2. 配置回读只有 hasApiKey，无明文。保存成功清空新 Key，失败保留输入。空输入保留已存 Key，移除使用独立明确操作。
3. Base URL 变更要求重新输入 Key，不把旧 Key 发往新地址。配置保存比对 revision，旧窗口不能覆盖新配置。
4. 远程 URL 必须 HTTPS，不允许 username/password、query/hash；HTTP 仅允许 localhost、127.0.0.1 或 ::1。本机请求也禁止重定向，不关闭 TLS 验证。
5. 原子保存专用配置文件。系统加密不可用或 basic_text 时，只允许明确选择仅本次运行；损坏/解密失败允许重新输入，不降级明文。
6. Key 不进入 worker、SQLite、备份、响应、提示词或日志。保存和测试独立；测试只发一条非任务的测试消息，说明所选服务可能计费。读取配置不联网。
7. 未配置 Key、离线或模型失败不影响本地 Todo。

## 拆解与采纳

1. active 主线下 available/blocked 任务可拆解，不必先选为当前。面板读取真实任务和主线快照，显示将发送的上下文、地址与可选补充要求。
2. 点击生成才发请求；发送前再次比对快照。展示 1–6 条建议：标题 1–200 字符，可选内容最多 2000；允许修改并选择至少一条。
3. 输出是不可信文本，严格解析和校验，不渲染 HTML、不执行代码。超长、非法 JSON 或无有效步骤返回错误，不写任务。
4. 同一窗口只运行一个请求。关闭或取消会中止；晚到结果不覆盖新请求或写任务。请求有超时，无自动重试，避免重复计费。
5. “应用所选步骤”说明会替换原任务。worker 同事务校验源版本及主线 active，原任务 superseded，新任务归属相同主线、parentActionId 指向原任务、继承原安排日；不自动设时间/精力。
6. 仅清除指向原任务的当前选择，其他当前任务不变，不自动选新任务；提交后任务视图、进度、画像和其他窗口刷新。
7. 稳定 operationId 保证同一内容重试返回既有结果；同一 ID 不同内容拒绝；事务失败不留半份步骤。
8. 成功面板内可撤销。原任务或新增任务被编辑、处理、继续拆解，或正在被选为当前时拒绝撤销，保护后续工作。允许时恢复原任务原状态/处理时间，将新增任务 abandoned，不覆盖其他当前选择。
9. 回执在本机保留，业务进程重启保持幂等；任务导入清回执与未应用预览。任务事实和来源保留于 v7 备份，Key 不随任务导入更改。
10. 关闭已应用面板后任务继续存在；首版只在结果面板提供撤销，完整历史管理不在范围内。

## 空状态、错误与恢复

- 无 Key 引导设置，不伪造建议。
- 401/403、429、网络/服务错误、超时使用固定中文错误，不显示服务商原始响应或 Key；保留补充要求和已有建议。
- 配置或任务变更明确要求重新读取，不自动换源或重发。
- 应用失败保留编辑/选择，可用同一 ID 重试；撤销冲突保留已应用事实。

## 用例与事务

固定 ai IPC：settings、save-settings、clear-key、test、source、generate、cancel、apply、undo。校验 trusted sender 与严格输入；Key 只交主进程配置用例。

worker：ai-source、ai-apply、ai-undo，身份由 worker 确定。快照包含任务/主线内容与状态，不仅比时间戳。网络请求不持有事务。

action_split_batches 保存幂等/撤销回执；任务、选择、来源与回执同事务。导入先清回执。预览在内存绑定窗口，其他窗口不能采纳。
