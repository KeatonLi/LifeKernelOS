## 用户结果

用户打开客户端即可记下想法、整理到主线、确认一项当前行动并完成。所有事实本地保存，关闭重开保持一致。界面有清晰层级和统一美感，不需要安装或启动服务器。

## 行为契约

1. 默认进入主线工作区，不出现登录、营销首页或虚构示例数据。空状态说明第一步；用户明确选择后才添加示例主线。
2. 两个一级导航：主线、我的画像。设置在底部，快速收集为抽屉；支持 Cmd/Ctrl+K 打开收集，Cmd/Ctrl+Shift+Space 全局打开收集小窗。
3. 主线展示真实派生进度、任务列表及详情。当前行动有独立视觉重点，支持专注小窗和完成、拆小、卡住、放弃、释放选择。阻塞任务可恢复为 available。
4. 当前行动的完成、拆小、卡住、放弃和释放携带 expectedActionId。与数据库当前选择不一致返回冲突并刷新；不得处理另一项行动。
5. Capture 与 Action 详细内容统一最多 2000 字符，转换保留全文。事务成功后所有打开窗口刷新任务、进度、画像与收集数量。
6. SQLite 在应用 userData 中；业务进程是事实源。窗口与渲染进程重启不能重置本地用户或记录。
7. JSON 导出使用原生保存对话框。导入 schemaVersion 6/7 时先校验字段、唯一 ID 和关系；显示将替换的数据数量，明确确认后自动备份并事务替换。取消或失败不修改原数据。不得导入密码或会话。
8. 启动时及导入前创建可恢复的 JSON 备份，保留最近 10 份；设置页允许打开数据目录和备份目录。写入原子化。
9. 外部导航、新窗口和权限请求默认拒绝。IPC 只接受本地应用窗口、已注册命令、合法输入；禁止任意路径、SQL、shell 或通用 Electron API。
10. 冷白工作区、石墨黑当前行动与朱橙操作强调，低噪声侧栏、细进度和清楚排版。配色通过语义 token 统一主线、画像、收集和专注小窗；正文与主要操作文本对比度至少 4.5:1。900px 主窗口及窄小辅助窗可用。键盘焦点可见、表单有标签、弹层支持 Escape 与焦点返回。

### 2026-10-07 恢复可靠性补充（Implemented）

- 备份中的主线、任务、收集与当前上下文必须来自同一个源用户；导入后统一映射为本地用户。当前行动 ID 与选择时间必须成对存在，混合身份或矛盾状态在替换前拒绝。
- 导入确认绑定读取备份时的工作区事实版本。确认期间其他窗口已提交修改时，拒绝本次替换并提示重新选择、核对及确认，保留最新记录；不得用旧确认覆盖新工作。
- 取消确认不写任务；版本冲突在生成导入备份与替换事务前返回。正常导入仍先备份、再事务替换，并广播刷新。

## 2026-10-07 桌面交付增量

> 状态：Implemented
> 决策依据：用户明确要求 GitHub 自动生成 macOS / Windows 的 ARM 与 x86 安装包；x86 在本轮指 x86_64（x64），ARM 指 ARM64。

- macOS ARM64 / x64 分别生成 DMG 与 ZIP，Windows ARM64 / x64 分别生成 NSIS 安装包；保留 Linux x64 的现有交付。
- 每个架构使用同架构 GitHub runner 执行领域测试、类型/生产构建与真实 Electron 启动、IPC、重启测试；任何目标失败均阻止正式发布。
- main 与手动运行在检查成功后打包；PR 执行检查，版本标签必须匹配 package.json 且指向 main 历史。打包后核对 Electron 可执行文件架构、asar 的 renderer / 主进程 / preload / worker / 迁移 / 品牌资源，并使用打包 asar 从临时 cwd 执行桌面闭环。
- 每个安装包有独立 SHA-256；发布前要求四个 macOS / Windows 架构和 Linux 现有产物完整、名称/版本正确且哈希有效。缺包、哈希缺失或错误、额外未知文件均阻止发布。
- 当前交付为未签名安装包；正式代码签名、公证、自动升级及实机人工安装验收保留为独立范围。自动检查不等同于实机安装验收。

验收标准：五个原生 CI 目标检查成功，生成八个安装包及对应哈希；篡改一个安装包、删除 Windows ARM64 或任意哈希文件时发布校验失败。实现与执行证据见 [CI/CD](../../development/ci-cd.md)。自动检查和配置实现不代替实际安装及人工验收，不将本增量标记 Verified。

## 验收场景

- 首次打开 → 建主线 → 快速记下 → 转为行动 → 选为当前 → 完成 → 数量与画像更新 → 重启仍保留。
- 2000 字符 Capture 转换完整保留，2001 字符被拒绝。
- 两个窗口同时打开：窗口 B 改选行动后，窗口 A 的旧完成请求返回冲突，B 的行动保持 available。
- 阻塞 → 恢复 → 再次选为当前；拆小保留来源并正确重算进度。
- 导出 → 新工作区导入 → 原始内容、关系、状态与当前行动保持一致；坏 JSON、断裂关系和取消导入不改变数据。
- 用不同 cwd 运行打包产物，迁移、品牌资源、SQLite 和界面均能加载。
- 实际 Electron 启动与渲染隔离检查；主线、收集、画像、设置及窄窗截图复核。
