# LifeKernelOS 功能规格索引

所有规格都必须经过评审后进入 `Accepted`，再开始实现。当前没有任何规格进入开发状态。

| 编号 | 名称 | 对应 PRD | 依赖 | 状态 |
| --- | --- | --- | --- | --- |
| `SPEC-0001` | 当前主线与行动 | 场景一、场景三完成分支 | 无 | Proposed |
| `SPEC-0002` | 根据状态选择下一步 | 场景二 | `SPEC-0001` | Proposed |
| `SPEC-0003` | 处理未完成行动 | 场景三 | `SPEC-0001` | Proposed |
| `SPEC-0004` | 日终收束 | 场景四 | `SPEC-0001`、`SPEC-0002` | Proposed |
| `SPEC-0005` | 快速捕捉 | 场景五 | `SPEC-0001` | Proposed |
| `SPEC-0006` | 周复盘 | 场景六 | `SPEC-0001`～`SPEC-0004` | Proposed |
| `SPEC-0007` | 数据导出与清空 | MVP 基础能力 | 本地存储 | Proposed |

## 开发顺序

```text
0001 → 0002 → 0003 → 0004 → 0006
  └──────────────→ 0005 ────┘
本地存储基础 ─────────────────→ 0007
```

`SPEC-0001`～`SPEC-0004` 是核心 MVP；`SPEC-0005`～`SPEC-0007` 在核心闭环通过首轮试用前不扩展实现范围。
